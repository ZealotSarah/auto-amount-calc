# 脱敏回归固件

本目录中的 Excel 文件全部使用人工构造的测试编码、医院名称和金额，不包含真实人员、机构、诊断、项目或 SQL 数据。

## sample_02_sanitized.xlsx

模拟样例 02 的关键结构：多个 Sheet、`符合范围金额1`、`数量1`、居民/职工、门诊/住院和其他险种。

使用通用规则、自动识别、廊坊市、三级、源 Sheet `With` 时：

- 居民门诊：`(20 + 40) × (50 + 210) ÷ (100 + 300) = 39.00`
- 居民住院：`100 × 56.84% = 56.84`
- 职工门诊：`30 × 100 ÷ 200 = 15.00`
- 职工住院：`50 × 84.58% = 42.29`
- 基金金额合计：`153.13`
- 处理 6 条、成功 5 条、排除 1 条、异常 0 条

## sample_03_sanitized.xlsx

模拟样例 03 的关键结构：第 3 行表头、`INSUTYPE`、`医疗总额`、`符合范围金额2`、数值险种代码和首个非空医院名称。

使用固定比例规则、自动识别、廊坊市、三级、源 Sheet `With` 时：

- 居民门诊：`50 × 56.84% = 28.42`
- 居民住院：`70 × 56.84% = 39.79`
- 职工住院：`40 × 84.58% = 33.83`
- 基金金额合计：`102.04`
- 处理 4 条、成功 3 条、排除 1 条、异常 0 条
